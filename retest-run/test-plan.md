# Тест-план ретеста

Объект: `app-fixed/index_refactor.html`, стенд `http://127.0.0.1:8080/index_refactor.html`.
Ожидания — `SPEC.md`, часть А (ссылки вида «п. 7» — на таблицу «Ожидания там, где описание
молчит», «КП» — на «Критерии приёмки продукта»).

Нумерация своя — `RT-TC-NNN`. Это **другой прогон по другой версии объекта**, и смешивать
его с `full-run/test-plan.md` нельзя: там статусы исходного объекта, здесь — исправленной копии.

## Условия прогона

- **Дата:** 2026-08-16. Проверки с относительными датами («завтра», «через год») считаются от неё.
- **Браузер:** Chromium 151.0.7922.34 (headless, Playwright 1.62.0). Версия снята
  из `browser.version` и `navigator.userAgent`, а не по памяти — вывод
  в `artifacts/environment-and-shots.txt`.
- **Ширина окна:** 1280×800 для всех проверок, кроме области K (375×812).
- **Предусловие для каждой проверки:** `localStorage` очищен **до** загрузки страницы,
  список пуст. Отдельные предусловия оговорены в самой проверке.
- **Консоль браузера собирается фоном** у каждого автотеста; ошибки роняют тест (область L).

## Формат

**Тип:** П — позитивная, Н — негативная, Г — граничная.
**Статус:** ✅ пройдена, ❌ провалена, ⚠️ пройдена с замечанием, ⛔ невыполнима.

Колонка «Артефакт» ссылается на: автотест из `tests-fixed/` (имя теста), вывод разведки
(`artifacts/probe-fixed.txt`, `artifacts/probe-fixed-2.txt` с номером раздела) либо снимок
экрана. Проверок без артефакта в этом плане нет.
