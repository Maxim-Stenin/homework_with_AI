# Журнал инструментов

> Только дополняется, старые записи не редактируются. Сюда попадает всё, что вы
> добавили в проект или окружение ради этой задачи: библиотеки, CLI-утилиты,
> линтеры, MCP-серверы, плагины и скиллы агента, хуки, внешние сервисы, контейнеры.
>
> Разовый вызов уже установленного инструмента сюда не пишется — он идёт
> в таблицу инструментов внутри файла сессии.
>
> Тупиковая попытка — тоже запись: поставили, не подошло, сняли. Это как раз интересно.

## Шаблон записи

```markdown
## YYYY-MM-DD · Сессия N · <инструмент> vX.Y

- **Тип:** библиотека / CLI / MCP / плагин / скилл / хук / сервис
- **Установка:** `<точная команда>`
- **Зачем:** какую задачу решает
- **Область:** проект или глобально
- **Проверка:** чем убедились, что работает
```

Удалённый или заменённый инструмент фиксируется так же — с пометкой
**удалён** / **заменён на X** и причиной.

## 2026-08-13 · Сессия 1 · Запреты в `.claude/settings.json`

- **Тип:** конфигурация разрешений (механизм под правила из `AGENTS.md`)
- **Установка:** создан файл `.claude/settings.json` с `permissions.deny` на необратимые
  команды (`git push --force`, `git reset --hard`, `git clean`, `git filter-branch`,
  удаление веток и тегов, `rm -rf`, `Remove-Item -Recurse`) и на правку `materials/`
  и `homework.pdf`; `permissions.ask` на коммиты, push и установку зависимостей
- **Область:** проект
- **Проверка: провалена.** Контрольный запуск заведомо запрещённой команды `git clean -n`
  (сухой прогон) **выполнился вместо блокировки**. Файл записан верно, но конфигурация
  не подхвачена: папки `.claude/` не существовало на старте сессии, наблюдатель за
  настройками её не отслеживает. Требуется перезапуск сессии и повторный контрольный
  запуск — до этого запреты считаются недействующими. Отмечено в `STATE.md`
  как известная проблема.
