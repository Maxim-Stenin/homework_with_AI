# Журнал инструментов

> Только дополняется, старые записи не редактируются. Сюда попадает всё, что вы
> добавили в проект или окружение ради этой задачи: библиотеки, CLI-утилиты,
> линтеры, MCP-серверы, плагины и скиллы агента, хуки, внешние сервисы, контейнеры.
>
> Разовый вызов уже установленного инструмента сюда не пишется — он идёт
> в таблицу инструментов внутри файла сессии.
>
> Тупиковая попытка — тоже запись: поставили, не подошло, сняли. Это как раз интересно.

## Шаблон записи

```markdown
## YYYY-MM-DD · Сессия N · <инструмент> vX.Y

- **Тип:** библиотека / CLI / MCP / плагин / скилл / хук / сервис
- **Установка:** `<точная команда>`
- **Зачем:** какую задачу решает
- **Область:** проект или глобально
- **Проверка:** чем убедились, что работает
```

Удалённый или заменённый инструмент фиксируется так же — с пометкой
**удалён** / **заменён на X** и причиной.

## 2026-08-13 · Сессия 3 · Python 3.14.7

- **Тип:** среда выполнения (нужна только ради стенда)
- **Установка:** установлена человеком вручную с python.org,
  путь `C:\Users\msten\AppData\Local\Programs\Python\Python314`
- **Зачем:** поднять статический стенд командой `python -m http.server 8080 --directory app`.
  `file://` под браузерными агентами заблокирован, значит объект нужно раздавать по HTTP.
  Выбран встроенный `http.server`, а не Node или сторонний сервер: раздача одного статического
  файла не стоит новой зависимости, а Node в системе всё равно нет.
- **Проверка: пройдена.** `python --version` → `Python 3.14.7`; стенд поднят,
  `Invoke-WebRequest` к `http://127.0.0.1:8080/index.html` вернул `HTTP 200 OK`, 20014 байт;
  страница открыта в браузерной панели, заголовок читается как «Мои финансы».
- **Подвох, стоивший времени.** В PATH лежит заглушка Python из Microsoft Store
  (`WindowsApps\python.exe`): на `--version` она отвечает словом `Python` без номера
  и кодом выхода 49. Выглядит как установленный интерпретатор, но им не является.
  Настоящий Python не попал в PATH этой сессии, потому что сессия стартовала раньше
  установки, — вызывался по абсолютному пути. Признак заглушки: **версия без номера**.

## 2026-08-13 · Сессия 4 · Скиллы `qa-manual` и `qa-autotest`

- **Тип:** скиллы агента, проектные
- **Установка:** написаны вручную, ничего не ставилось:
  `.claude/skills/qa-manual/SKILL.md` и `.claude/skills/qa-autotest/SKILL.md`
- **Зачем:** `qa-manual` — порядок ручной проверки: наивный прогон, формат `TC-NNN`,
  правило «проверять отсутствие записи, а не только сообщение об ошибке», что считать
  дефектом, а что замечанием. `qa-autotest` — структура `tests/`, фикстуры, порядок
  предпочтения селекторов по существующей разметке и главное правило «тест на дефекте
  обязан падать; чинится тест, но никогда не объект».
- **Область:** проект — едут в репозиторий вместе со сдачей, в отличие от глобальных
- **Почему свои, а не готовые:** поиск по доступным скиллам (ручное тестирование,
  тест-план, баг-репорты, Playwright, exploratory) вернул **пустой результат**.
  Готовых нет. Задним числом это к лучшему: внешний скилл принёс бы свой формат
  баг-репорта, который разошёлся бы с форматом из `AGENTS.md`.
- **Проверка: не выполнена на момент записи.** Файлы созданы, но ни один скилл ещё
  не срабатывал в деле — проверкой будет первая сессия тестирования: подхватился ли
  скилл по описанию и повлиял ли на поведение агента. До этого считать непроверенным.
- **Дополнение той же сессии — скиллы расширены по требованию человека** («сделать
  количество проверок и глубину выше»). Добавлены справочники:
  `qa-manual/references/checklist.md` — каталог из 186 проверок по 14 областям
  с типом (позитивная / негативная / граничная) и ссылкой на пункт `SPEC.md`;
  `qa-autotest/references/patterns.md` — рецепты кода: фикстуры стенда и чистого
  хранилища, параметризация классов эквивалентности, диалоги подтверждения, выгрузка
  и загрузка файлов, инварианты, тесты на дефектах.
  В сами `SKILL.md` добавлены разделы про техники проектирования проверок, нормы объёма
  и глубины, слои проверок и детерминизм. Справочники вынесены отдельными файлами
  намеренно: подгружаются по ссылке, а не раздувают скилл при каждом срабатывании.
