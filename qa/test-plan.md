# Тест-план

Объект: `app/index.html`, стенд `http://127.0.0.1:8080/index.html`.
Ожидания — `SPEC.md`, часть А (ссылки вида «п. 7» — на таблицу «Ожидания там,
где описание молчит», «КП» — на «Критерии приёмки продукта»).

## Условия прогона

- **Браузер:** Chromium 151.0.7922.34 (headless, Playwright 1.62.0).
- **Ширина окна:** 1280×800 для всех проверок, кроме области K (375×812).
- **Предусловие для каждой проверки:** `localStorage` очищен, страница перезагружена,
  список пуст. Отдельные предусловия оговорены в самой проверке.
- **Дата прогона:** 2026-08-16. Проверки с относительными датами («завтра», «через год»)
  считаются от неё.
- **Консоль браузера открыта весь прогон**, ошибки собираются фоном (область L).

## Формат

Скилл `qa-manual` описывает проверку блоком из семи полей. Здесь те же поля сведены
в таблицу: при 111 проверках блочный формат дал бы 800 строк, в которых не видно
ни областей, ни границ парами. Поля «Предусловие» и «Область» вынесены в заголовок
раздела, остальные — колонки.

**Тип:** П — позитивная, Н — негативная, Г — граничная.
**Статус:** ✅ пройдена, ❌ провалена, ⚠️ пройдена с замечанием, ⛔ невыполнима.
