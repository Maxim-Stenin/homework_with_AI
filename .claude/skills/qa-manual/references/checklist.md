# Каталог проверок

Материал для тест-плана, а не сам тест-план. Здесь кандидаты: вход, действие и тип.
**Ожидаемый результат берётся из `SPEC.md`, часть А** — в каталоге он не дублируется,
иначе разойдётся со спецификацией при первой же правке. Столбец «SPEC» указывает пункт
таблицы ожиданий или раздел.

Тип: **П** — позитивная, **Н** — негативная, **Г** — граничная.

Идентификаторы каталога (`SUM-01`) — рабочие. В тест-плане проверки получают
сквозные номера `TC-NNN`, а ссылка на каталог указывается в поле «Область».

Отбирать нужно осмысленное: каталог заведомо шире одного прогона. Пропущенная область —
это решение, и его надо назвать в отчёте, а не оставить молча.
